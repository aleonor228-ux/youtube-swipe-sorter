Storage & Privacy
All video metadata, classifications, and preferences are stored exclusively in your local browser’s IndexedDB. No backend servers or tracking exist.
YouTube Data API Setup

How to get a free YouTube Data API v3 key:

  1. Visit the Google Cloud Console.
  2. Create a new project (e.g. YouTube Sorter).
  3. Go to APIs & Services > Library, search for YouTube Data API v3, and click Enable.
  4. Go to Credentials > Create Credentials > API Key.
  5. Copy your key and paste it into the Import tab. Google gives 10,000 free quota units per day (enough for ~50,000 video metadata fetches daily).
Security Notice: In a client-side web application, any API key entered is stored locally in your browser’s IndexedDB. For maximum security, restrict your key in Google Cloud Console to the YouTube Data API v3.
Fixing YouTube Player Error 153
Why did Error 153 happen?
You opened this file directly from your phone's storage (content:// or file://). YouTube's security policy strictly blocks embedded video playback without a valid http:// or https:// origin.

Easy Solutions:

Option 1: Open via Local Wi-Fi (Recommended)
Since your computer is running a local server on your Wi-Fi/Hotspot, open this address in Chrome on your phone:
http://10.151.126.42:8080/index.html
(Ensure phone and computer are connected to the same Wi-Fi or phone hotspot)
Option 2: Host for Free on GitHub Pages or Vercel
Because this is a single static index.html file with no backend, you can drop it into any GitHub repository and turn on GitHub Pages, or drag-and-drop it into Vercel / Netlify / Cloudflare Pages to get a permanent free HTTPS web link you can bookmark on your phone!
Option 3: Tap "YT ↗" to inspect in YouTube App
You can still swipe, organize, and sort all videos offline or locally. Whenever you want to preview an unavailable video, tap the YT ↗ button on the card to open it directly in the YouTube app.
